# Game context (paste into every AI session)
Game: single-player quantum teaching game about SUPERDENSE CODING (quriosity, option 5). 20 levels, one mode.
Vocabulary: parcel (qubit), twin (entangled pair), lens (measurement basis), flip (X), twist (Z), lens-changer (H).
Physics rules:
- The twin pair is prepared BEFORE the message. Only Alice's qubit travels.
- Alice acts only on her own qubit: nothing, flip, twist, or flip+twist = 00, 01, 10, 11.
- Bob needs BOTH qubits. Decode = CNOT then H, then read both.
- One qubit alone looks like a coin flip, whichever message was sent.
- Never say a qubit "holds 2 bits". Never call this a secure channel.
Rules for AI tools: only edit files in my own folder. Do not change quantum rules. If unsure about physics, say so.
